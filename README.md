# Rad Pro Demo

A lightweight demo prototype for the Rad Pro game menu with two explicit game modes:
- Chess
- Tetris

This repository includes a Material-inspired dark theme designed around the Google Workspace aesthetic: charcoal surfaces, soft blue accents, clean cards, and strong contrast.

## Run locally

Open this file directly in a browser:

- `demo/index.html`

Or serve the folder with any local static server:

```bash
cd demo
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
